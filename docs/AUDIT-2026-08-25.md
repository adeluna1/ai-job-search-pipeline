# Security, Privacy, and Release Audit

Audit date: 2026-08-25

Scope: Expedient Employment 2.0.0 tracked source, bundled dependencies, portable archive, per-user Windows installer, installed control service, only-cli runtime, recruiting acceptance suite, and scheduled wake task.

## Result

The source snapshot, portable payload, installed backend, and scheduled wake passed the release gates below. No employer-facing action was performed. All job and application records used for high-volume acceptance were synthetic.

One distribution advisory remains: the Windows installer is not Authenticode-signed because no product signing certificate is configured. The artifact is reproducible from the documented build command, but Windows may show an unknown-publisher warning.

## Static analysis

Bandit 1.9.4 scanned `job_pipeline` after remediation:

- high severity: zero;
- medium severity: zero;
- low severity: nine.

The remaining low notices cover guarded subprocess imports and calls, the locally bounded XML parser, and one test-style assertion. Subprocess handlers use fixed executables or validated paths, argument arrays, `shell=False`, timeouts, output caps, and redacted errors. DOCX parsing rejects DTD and entity declarations before parsing.

Security improvements made during the audit:

- replaced the non-security SHA-1 content fingerprint primitive with SHA-256;
- rejected XML DTD and entity declarations in resume uploads;
- applied DNS-aware public-address validation to only-cli page URLs;
- applied the safe public URL policy before legacy WebClaw page requests;
- limited Resume-Matcher to loopback HTTP;
- enabled the Electron sandbox and central webview attachment policy;
- denied renderer permissions and popups by default;
- added a restrictive renderer Content Security Policy;
- restricted webviews to fixed loopback services or approved session domains.
- made scheduler storage safe across the control service's concurrent HTTP request threads.
- disabled Python bytecode writes for packaged desktop and scheduled command paths.
