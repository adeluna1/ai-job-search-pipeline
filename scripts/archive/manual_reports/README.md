# Archived manual report scripts

These scripts are historical, date-specific report builders and raw diagnostic
helpers. They are retained only for audit/reference and are not supported
production entry points.

Use the maintained pipeline instead:

1. `agent-a-find` for bounded discovery, verification, exclusions, and ranking.
2. `agent-b --live` for an independent live review and Agent C handoff.
3. `agent-c` for an integrity-bound private packet.
4. `agent-c-browser` for an approval-gated browser plan or execution.

Do not copy hard-coded jobs from this archive into a new report. Every new search
must rediscover and reverify the employer-controlled posting.
